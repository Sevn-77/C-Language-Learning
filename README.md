# C 语言大学生成绩管理系统

一个面向 C 语言入门学习的命令行成绩管理项目。当前版本支持录入和维护学生的 C 语言、高等数学、大学英语成绩，并将记录保存在本地 CSV 文件中。

## 功能

- 添加学生，使用学号标识学生并检查学号重复。
- 查看全部学生信息和各科成绩。
- 按姓名或姓名片段查找学生。
- 修改指定学生的一门课程成绩。
- 删除学生记录。
- 计算每位学生的三科平均分和各科班级平均分。
- 校验必填字段、分数范围（0–100）和无效菜单输入。
- 启动时载入 `students.csv`，添加、修改和删除后保存。

## 技术与数据格式

- C11 标准库；不依赖第三方 C 库。
- 固定容量数组，最多保存 200 位学生。
- `students.csv` 是逗号分隔文本记录：学号、姓名、班级、C 语言、高等数学、大学英语。文件字符编码取决于运行程序时的终端编码；建议使用 UTF-8 终端。
- 每次启动时从当前工作目录读取 `students.csv`。没有该文件时以空名单启动。
- 学生信息属于个人数据。请勿把真实学生成绩提交到公开仓库；`.gitignore` 已忽略项目根目录下的 `students.csv`。

## 编译与运行

需要安装 GCC（支持 C11）。在项目根目录执行：

### Windows PowerShell

```powershell
gcc -std=c11 -Wall -Wextra -Wpedantic -O2 student-management/main.c -o score_manager.exe
chcp 65001
./score_manager.exe
```

### macOS / Linux

```sh
gcc -std=c11 -Wall -Wextra -Wpedantic -O2 student-management/main.c -o score_manager
./score_manager
```

程序会在当前工作目录创建或更新 `students.csv`。如需保留数据，请备份该文件；不要将真实数据放进 Git。

## 自动化测试

需要 Python 3 和 GCC。在项目根目录执行：

```sh
python -m unittest discover -s tests -v
```

测试会在临时目录编译程序并运行，不会在项目目录生成可执行文件或测试成绩文件。当前测试覆盖菜单退出、无效菜单输入、学生增查改删、统计和 CSV 持久化。每次实际执行情况见 [`docs/test-report.md`](docs/test-report.md)。

## 当前限制

- 只支持 C 语言、高等数学和大学英语三门课程，不能在运行时添加课程。
- 最多 200 位学生；不支持多个班级的独立统计、排序和排名。
- 姓名搜索区分大小写；没有按学号查找的菜单功能。
- CSV 字段不能包含英文逗号；数据文件损坏时无效行会被跳过并提示。
- 不提供图形界面、账号权限、数据加密、云同步或并发访问。
- 课程分数必填，当前没有缺考或未录入状态。

## 开发协作说明

本项目使用 OpenAI Codex 辅助实现 C 代码、自动化测试和项目文档。学生本人提出了项目目标、功能需求和 GitHub 展示要求；建议本人在提交前亲自编译运行、检查代码，并据实补充其他参与工作。测试报告记录的是本次工作环境中实际尝试的命令和结果，不代表学生本人已完成运行审核。
